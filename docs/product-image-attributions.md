# Product photo attributions

Seed-data product photos sourced via the [Openverse API](https://api.openverse.org),
which indexes openly-licensed images (CC0, public domain, CC BY, CC BY-SA) from
providers like Wikimedia Commons and Flickr. Kept here to satisfy CC BY / CC BY-SA
attribution requirements for the non-CC0 photos below. One entry per product,
reflecting the photo currently live on that product (a first pass matched a few
products to irrelevant photos by keyword collision -- e.g. "Frying Pan Spring", a
Yellowstone location -- those were replaced with better matches; this file lists
only the final result).
